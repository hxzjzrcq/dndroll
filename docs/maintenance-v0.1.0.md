# DNDROLL v0.1.0 定向维护记录

## 确认与修复

- P1 属实：restoreSaved 返回错误及 null session 后，原自动保存 Effect 立即 removeItem。现有损坏数据（包括空字符串）在用户明确清除前阻止自动保存写入或删除。新建会话仍可操作，但不会覆盖损坏数据，界面双语提示自动保存暂停。明确清除后若已有当前会话，立即正常保存；没有当前会话则删除旧存档。有效存档恢复与正常自动保存保持原流程。
- P2 属实：版本按钮原本只改选择，旧会话继续显示；每次 session 更新的同步 Effect 又强制拉回旧选择。现版本与方法均只浏览，显示浏览提示、返回当前会话按钮及所选方法配置；当前会话保留标题与操作区。只有开始生成、显式新建或导入才替换/结束会话，已有事件时沿用原确认框。取消不改变会话或存档。导入成功时显式同步导航，日常操作不重置浏览选择。
- P3 属实：README 的未完成 UI、等待 Claude 等描述失效。只更新当前工程状态、使用入口、文件用途与 web 命令；保留有效 Core、接口、规则限制及开发说明。
